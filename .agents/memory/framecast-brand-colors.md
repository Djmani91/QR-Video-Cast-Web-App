The user wants the FrameCast website and native app to share the purple, yellow, and white palette. Exact shades are defined in each artifact's theme tokens.

**How to apply:** Keep the web and native app palettes aligned when changing FrameCast branding; preserve existing functional flows and use tints of these colors for borders and surfaces.
